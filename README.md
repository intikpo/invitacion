# Invitación digital de boda

## Archivos
| Archivo | Para qué sirve |
|---|---|
| `config.js` | **Aquí cambias todo**: nombres, fecha, lugar, mapa, mensajes, QR, fotos, fecha límite, URL del backend |
| `index.html` | Estructura. El itinerario (horas) se edita directamente aquí, en la sección "Itinerario" |
| `style.css` | Colores (arriba del archivo, `:root`) y animaciones |
| `script.js` | Lógica (no necesitas tocarlo) |
| `Code.gs` | Backend: se pega en Google Apps Script |
| `images/` | Fotos (`portada.jpg`, `jardin.jpg`, `mesa.jpg`, `flores.jpg`, `cierre.jpg`) y `qr.png` |
